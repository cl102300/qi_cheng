# Heart Memories - 三维浪漫记忆相册

带账户登录的照片收藏系统，提供精致照片墙与可选的三维展览；同一账户可在多台设备共享照片。

## ✨ 核心特性

### 📸 私人照片收藏
- 首次打开显示空相册引导，不依赖远程示例图片。
- 支持批量添加 JPG、PNG、WebP 图片，也可以拖拽导入。
- 展示用缩略图会统一裁切为 4:5 胶片画幅并加轻微暖调；大图查看显示原图。
- 原图以 BLOB 保存在服务器 SQLite 数据库，缩略图和照片信息也保存在数据库中。
- 点击照片可放大查看，并用左右方向键切换；可删除单张照片或清空相册。
- 登录同一账户的手机可以上传、查看和删除同一本相册中的照片。
- 旧版本保存在本机浏览器的照片，可登录后通过「导入旧照片」上传到账户。
- 最多保存 999 张；单张照片上限为 25 MB。

### 🌌 可选三维展览
- 照片沿螺旋轨道分布，支持旋转、缩放、布局切换和大图查看。
- 自动按数量切换布局：0–20 张圆环（空相册不显示三维场景）、21–99 张爱心、100–499 张球体、500–999 张多层星系。
- 照片较多时精简三维相框装饰，减少渲染负担。

### 🎵 音乐联动
- 播放/暂停控制
- 音量调节
- 时间显示
- 场景切换时保持音乐状态

## 🚀 快速开始

运行环境需要 Node.js 22.13 或更高版本（包含内置 SQLite 模块）。

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 启动已构建的生产服务
npm start
```

开发模式下打开终端显示的前端地址（默认 `http://localhost:3000/`）。首次使用时创建账户；另一台手机登录相同账户即可访问同一相册。开发时，手机也可以访问电脑显示的局域网地址。

生产模式需先运行 `npm run build`，再运行 `npm start`。默认监听 `0.0.0.0:3000`，数据库保存在 `data/heart-memories.sqlite`。

## 云服务器部署

安装 Docker 和 Docker Compose 后，在项目目录运行：

```bash
docker compose up -d --build
```

Compose 会将数据库保存在 Docker 持久卷 `heart_memories_data` 中，容器重建后照片仍会保留。对公网提供服务时，请在前面配置 HTTPS 反向代理；生产环境默认启用安全登录 Cookie。备份时需停止容器后备份持久卷中的 SQLite 数据库文件。

| 环境变量 | 默认值 | 用途 |
|---|---|---|
| `PORT` | `3000` | HTTP 端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DATABASE_PATH` | `data/heart-memories.sqlite` | SQLite 数据库文件路径 |
| `COOKIE_SECURE` | 生产环境开启 | 登录 Cookie 是否仅通过 HTTPS 发送 |

## 🔧 技术栈

- **React 18** + **TypeScript** - 现代化前端框架
- **Vite 6** - 极速开发体验
- **Three.js** + **React Three Fiber** - 三维渲染
- **Zustand** - 轻量级状态管理
- **Node.js 22.13+** - 内置 HTTP 服务与 SQLite 支持
- **SQLite** - 账户、登录会话、照片信息、缩略图和原图存储

## 🔒 隐私保护

- ✅ 账号密码使用 scrypt 哈希，登录 Cookie 设置 HttpOnly
- ✅ 照片按账户隔离；JPG、PNG、WebP 原样保存，其他可解码图片自动转为 JPG
- ✅ 不调用云端图像识别服务
- ✅ 照片保存在服务器 SQLite 数据库，Docker 部署提供持久卷
- ✅ 用户可随时清空账户相册

## 🎯 使用指南

1. **首次打开**：显示空相册，可点击「选择照片」开始创建收藏
2. **添加照片**：点击「添加照片」按钮，或拖拽图片到页面
3. **浏览照片**：
   - 鼠标拖动旋转视角
   - 滚轮缩放
   - 点击照片查看详情
   - 展示形状仅根据照片数量自动变化，不提供手动布局或主题选择
4. **删除照片**：照片卡片上的删除按钮，或大图下方「删除这张照片」
5. **清空相册**：照片墙右上角「清空相册」按钮
